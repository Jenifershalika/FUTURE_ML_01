# 📊 Customer Segmentation

## 📌 Project Overview

This project focuses on segmenting customers based on their purchasing behavior using **K-Means Clustering**. The goal is to identify different customer groups to help businesses make better marketing and sales decisions.

---

## 🎯 Objective

* Group customers into segments based on:

  * Sales
  * Profit
  * Quantity
* Identify high-value and low-value customers
* Provide business insights for decision-making

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* Scikit-learn
* Matplotlib

---

## 📂 Dataset

* Dataset used: Superstore Sales Dataset
* Key columns:

  * Customer ID
  * Sales
  * Profit
  * Quantity

---

## ⚙️ Implementation Steps

1. Import dataset using Pandas
2. Select required columns (Customer ID, Sales, Profit, Quantity)
3. Handle missing values
4. Group data by Customer ID
5. Normalize the data using StandardScaler
6. Apply K-Means clustering
7. Determine optimal clusters using Elbow Method
8. Visualize clusters using scatter plot

---

## 📊 Results

* Customers were segmented into **3 clusters**:

  * **High-Value Customers** 💰
  * **Medium-Value Customers** 📊
  * **Low-Value Customers** ⚠️

---

## 🔍 Key Insights

* High-value customers contribute the majority of revenue
* Medium-value customers can be converted into high-value customers
* Low-value customers generate minimal profit
* Discounts may reduce overall profitability

---

## 📈 Output

* Clustered dataset (`customer_segments.csv`)
* Visualization of customer segments
* Business insights report

## 🚀 Business Impact

Customer segmentation using K-Means helps businesses understand customer behavior and make data-driven decisions to enhance performance.
